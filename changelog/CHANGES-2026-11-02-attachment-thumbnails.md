# 2026-11-02 — 上传附件：缩略图 + 点击放大查看

**以前**：选好文件后只显示一排文件名，提交前无法确认是不是正确的照片 / 视频 / PDF。

**现在**（所有 Issue Submission 表单 + TG Reply Threads 的「Generate to another Topic」）：

- 文件直接在上传框里显示成方形缩略图：照片显示图片；视频显示画面 + ▶ + VIDEO 标签；PDF 显示 📄 PDF。
- 每张下面有文件名，右上角红色 × 删除；后面有「＋ Add more」，满 5 个自动隐藏。
- **点缩略图放大查看**：
  - 照片：点击或滚轮放大（最多 5 倍），放大后可拖动；右上角 🔍 切换。
  - 视频：直接播放。
  - PDF：直接显示内容。
  - 左右箭头 / 键盘 ← → / 下方小图切换；Esc、✕ 或点空白处关闭（在转发弹窗里按 Esc 只关闭查看器，不会关掉转发窗口）。
- 跳过的文件会写清楚原因（超过 5 个 / 超过 20MB / 合计超过 30MB）。
- 同一个文件删除后可以重新选择（以前选同一个文件不会有反应）。

文件还是在按 Submit 时才上传，查看完全在浏览器本地进行，不会多用流量或存储。
